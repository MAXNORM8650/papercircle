\begin{abstract}
Paper Circle is a multi-agent research discovery and analysis system designed to reduce the effort required to find, assess, and organize academic literature. The system integrates offline and online retrieval, multi-criteria scoring, and diversity-aware ranking while maintaining fully reproducible outputs at each agent step. It is implemented using the smolagents framework as a baseline for tool-calling agents, and extends this baseline with stateful orchestration, structured exports, and evaluation metrics. This paper describes the architecture, agent roles, retrieval pipelines, scoring functions, and evaluation interfaces that together form the Paper Circle discovery workflow.
\end{abstract}
