\section{Conclusion}
Paper Circle demonstrates how a multi-agent discovery workflow can unify heterogeneous search sources, scoring strategies, and export formats into a reproducible research tool. By building on smolagents, the system retains a simple agent-tool interface while extending it with shared state, deterministic ranking, diversity controls, and evaluation metrics. The result is a practical pipeline for research discovery and analysis that integrates smoothly with collaborative reading workflows. Future work includes richer citation-based authority metrics, improved semantic retrieval for offline corpora, and formal evaluation on curated benchmarks.
